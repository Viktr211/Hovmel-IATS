## 🔥 Возможности

- 📊 **График как в MT5** — свечи, SMA, уровни входа и усреднения
- 🟢🔴 **Световые индикаторы** — ДЕМО / РЕАЛ режимы
- 📈 **Несколько инструментов** — BTC, ETH, SOL, XRP
- 🎯 **Управление рисками** — фиксированный риск на сделку, стоп-лосс
- 🔄 **Усреднение** — с геометрическим увеличением лота
- 🔁 **Переворот** — при достижении лимита усреднений
- 🧪 **Трейлинг-стоп** — фиксация прибыли при движении цены
- 📋 **Журнал событий** — цветная кодировка (успех/ошибка)
- 📊 **Эксперт** — статистика, история сделок (синий/красный), график equity
- ☁️ **Доступен из любой точки мира** — после деплоя на Streamlit Cloud

## 🛠️ Технологии

- Python 3.10+
- Streamlit — веб-интерфейс
- Plotly — интерактивные графики
- CCXT — подключение к OKX
- Pandas / NumPy — обработка данных
